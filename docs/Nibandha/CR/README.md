# Nibandha Change Requests

This directory contains change requests (feature requests) for the Nibandha library discovered during Pravaha integration.

## Format

Each CR should be documented in a separate markdown file with:
- **CR ID**: Unique identifier
- **Title**: Brief description
- **Context**: Why this feature is needed
- **Proposed Solution**: Suggested implementation
- **Priority**: High/Medium/Low
- **Workaround**: Current solution in Pravaha (if any)

## Sharing with Nibandha Team

These CRs will be shared with the Nibandha development team as our dependency is directly from their GitHub repository.
