# Nibandha Bug Reports

This directory contains bug reports for the Nibandha library discovered during Pravaha integration.

## Format

Each bug should be documented in a separate markdown file with:
- **Bug ID**: Unique identifier
- **Title**: Brief description of the issue
- **Steps to Reproduce**: How to trigger the bug
- **Expected Behavior**: What should happen
- **Actual Behavior**: What actually happens
- **Environment**: OS, Python version, Nibandha version
- **Severity**: Critical/High/Medium/Low
- **Workaround**: Temporary solution in Pravaha (if any)

## Sharing with Nibandha Team

These bug reports will be shared with the Nibandha development team as our dependency is directly from their GitHub repository.
